# คำนวณไทยช่วยไทย พลัส 60/40

เว็บคำนวณอย่างไม่เป็นทางการสำหรับช่วยตอบคำถามว่า ถ้าเงินรัฐที่เหลือวันนี้มีจำนวนหนึ่ง ควรซื้อของไม่เกินกี่บาทเพื่อใช้สิทธิไทยช่วยไทย พลัส 60/40 ให้หมดพอดี

เปิดใช้งานจริง: https://thai-chuai-calc.vercel.app/

## ฟีเจอร์

- กรอกเงินรัฐที่เหลือวันนี้ แล้วคำนวณยอดซื้อสูงสุด
- กรอกราคาสินค้า แล้วคำนวณว่ารัฐช่วยจ่ายเท่าไหร่ และลูกค้าจ่ายเองเท่าไหร่
- โหมดร้านค้าใส่เงินรัฐที่ลูกค้าเหลือแบบ optional ได้ เผื่อลูกค้าเหลือไม่เต็ม 200 บาท
- ปุ่มลัด 200 / 150 / 100 / 80 / 50 / 30 บาท
- ปุ่มคัดลอกและแชร์ผลลัพธ์
- ตารางเงินรัฐเหลือยอดฮิตและ FAQ สำหรับ SEO
- sitemap.xml และ robots.txt สำหรับ Google Search Console

## สูตรคำนวณ

โครงการใช้สัดส่วน 60/40:

```txt
รัฐช่วยจ่าย = 60%
ผู้ใช้สิทธิจ่ายเอง = 40%
ยอดซื้อสูงสุด = เงินรัฐที่เหลือ / 0.60
```

ตัวอย่าง:

```txt
เงินรัฐเหลือ 200 บาท
ซื้อของได้สูงสุด 333.33 บาท
เราจ่ายเองประมาณ 133.33 บาท
รัฐช่วยจ่าย 200 บาท
```

ถ้าราคาสินค้าเกินยอดที่ใช้เพดานรัฐได้พอดี ระบบจะคำนวณให้รัฐช่วยสูงสุดตามเงินรัฐที่เหลือ และส่วนที่เกินลูกค้าจ่ายเองเต็มจำนวน

## วิธีรันในเครื่อง

ติดตั้ง dependency:

```bash
npm install
```

รัน dev server:

```bash
npm run dev
```

เปิดเว็บ:

```txt
http://localhost:3000
```

## วิธี Build

```bash
npm run build
```

## URL สำคัญหลัง Deploy

```txt
https://thai-chuai-calc.vercel.app/
https://thai-chuai-calc.vercel.app/sitemap.xml
https://thai-chuai-calc.vercel.app/robots.txt
```

## ส่งให้ Google เจอ

หลัง Deploy แล้วให้ทำใน Google Search Console:

1. Add property แบบ URL prefix
2. ใส่ `https://thai-chuai-calc.vercel.app/`
3. Verify ownership
4. Submit sitemap: `sitemap.xml`
5. ใช้ URL Inspection กับหน้าแรก แล้วกด Request Indexing

## หมายเหตุสำคัญ

เว็บไซต์นี้เป็นเครื่องมือคำนวณอย่างไม่เป็นทางการ ไม่ใช่เว็บไซต์ของหน่วยงานรัฐ กรุณาตรวจสอบสิทธิและข้อมูลจริงผ่านแอปเป๋าตังหรือช่องทางทางการของโครงการเสมอ
